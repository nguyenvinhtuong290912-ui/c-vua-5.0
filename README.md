# Cờ Vua — Royal Clash

## Chạy trên máy tính
1. Cài Python 3.10 trở lên.
2. Mở terminal trong thư mục dự án.
3. Chạy `pip install -r requirements.txt`.
4. Chạy `streamlit run app.py`.

## Đưa lên GitHub + Streamlit Community Cloud
1. Tạo repository mới trên GitHub.
2. Tải lên `app.py`, `requirements.txt`, và `README.md`.
3. Trên Streamlit Community Cloud chọn repository đó và đặt **Main file path** là `app.py`.
4. Nhấn Deploy.

Bàn cờ dùng chessboard.js và chess.js qua CDN, nên trình duyệt cần có kết nối Internet để tải thư viện và ảnh quân cờ.
